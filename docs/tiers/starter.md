## Modules unlocked (lesson-only)

### Module 1 — Wallet foundations

- **Beats:** Wallet = your keys + an address. Receive first, send second. Practice before real money.
- **Practice (later / Certified):** Create → receive → send in a simulated wallet.
- **Starter deliverable:** Read the cues; download the “create / receive / send” cheat sheet.

### Module 2 — Exchange & spot basics

- **Beats:** Exchange is the parking garage — useful, not ownership. Spot = buy/sell at a price. Network choice matters on deposits.
- **Practice (later / Certified):** Simulated market vs limit + deposit-network check.
- **Starter deliverable:** Lesson + “orders & networks” cheat sheet.

### Module 3 — Self-custody

- **Beats:** Exchange balance is an IOU. Seed phrase = master key. Offline storage only.
- **Practice (later / Certified):** Simulated wallet setup + seed hygiene checklist.
- **Starter deliverable:** Lesson + seed-phrase protocol cheat sheet.

### Module 4 — Risk & hygiene

- **Beats:** Phishing and fake support. Approvals that drain. Tiny test transfer before big moves.
- **Practice (later / Certified):** Simulated “spot the scam” + test-transfer checkpoint.
- **Starter deliverable:** Lesson + hygiene checklist cheat sheet.
